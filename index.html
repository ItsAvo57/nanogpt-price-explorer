API Access (for developers)

Get a prepaid API key by sending Nano to the gateway. Each key gives you access to the relay API.

REST API

POST /chat — Chat completion

curl -X POST https://your-relay.com/chat \
  -H "Content-Type: application/json" \
  -H "X-Api-Key: your-prepaid-key" \
  -d '{
    "model": "gpt-4.1-nano",
    "messages": [{"role":"user","content":"Hello!"}]
  }'

GET /balance — Check your balance

curl https://your-relay.com/balance \
  -H "X-Api-Key: your-prepaid-key"

Getting a key

Send Nano to the gateway address above. Include your desired API key name in the memo. The relay will create a prepaid balance equal to the USD value of your Nano minus 20% markup.
